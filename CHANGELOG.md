# Changelog

## 0.1.0

First public pre-release.

- Edit the headings of a Markdown file as a mind map, beside the text or in place of it.
- Map edits change only the headings they touch; all other text keeps its exact bytes.
- Text edits appear on the map, keeping selection and folded branches.
- A map edit based on an outdated version of the file is refused rather than applied.
- Colors follow the VS Code theme, including light and high contrast themes.
